# Hoodie print: "a very Turkish time" (GPT Image 2.5)

Settings: size 1024x1536 (2:3), output PNG, background `transparent`.
Intended for a heather-grey or sand hoodie (the navy linework and off-white ink need a light-to-mid garment).

## Prompt

